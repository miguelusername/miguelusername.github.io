FrogBlog — Express / TypeScript / MongoDB

Carries the software design and database enhancements. Originally built with a team for CS-465.

VersionBrowseNotes
Original artifacts/frogblog/original As it stood before this course. Flat listeners/ folder, no middleware, no validation, no tests.
Enhanced artifacts/frogblog/enhanced Layered architecture, shared auth middleware, Zod validation, normalized collections, indexes, transactions, schema validators, and 31 tests.

Files worth looking at first

FileWhat it shows
middleware/auth.tsThe shared authentication middleware that replaced the copy-pasted session checks
errors.tsHttpError and the single error handler every failure routes through
models/schema.tsThe $jsonSchema collection validators
models/index.tsTyped collections and the index definitions, including the unique compound index
services/post.service.tsThe cascading delete inside a transaction
tests/integration/constraints.test.tsTests that prove the database rejects what it should

Running it

cd backend
npm install
npm run typecheck   # TypeScript, strict
npm test            # 8 unit tests, no database needed
npm run test:db     # 23 integration tests against a real MongoDB
npm run dev         # http://localhost:3000

MongoDB must be running as a single-node replica set — the cascading delete uses a transaction, which MongoDB only supports on a replica set. npm run test:db reads .env.test and refuses to run unless the database name ends in _test.

Zombie Taxi — Unity / C#

Carries the algorithms and data structures enhancement. Originally built with a team for GAM-360.

VersionBrowseNotes
Original artifacts/zombie-taxi/original Per-frame scene searches, unthrottled path solving, no distance awareness, no tests.
Enhanced artifacts/zombie-taxi/enhanced Spatial hash grid, round-robin scheduler, level-of-detail selector, repath policy, and 37 tests.

Scope note. Zombie Taxi is an unreleased commercial project, so only the gameplay scripts and assembly definitions are published here. The Unity project itself — scenes, prefabs, art and audio — stays private. The code shown is the whole of what changed in this enhancement.

Files worth looking at first

FileWhat it shows
AI/Core/SpatialHashGrid.csThe uniform spatial hash grid
AI/Core/UpdateBudgetScheduler.csThe round-robin frame scheduler
AI/Core/AiDetailBands.csDistance-based level of detail
AI/ZombieManager.csCached player reference, registry, spatial index and budget
Tests/EditMode/SpatialHashGridBenchmark.csThe benchmark behind the 20× figure
Tests/EditMode/ChaseRepathPolicyTests.csThe regression test that caught the attack bug

Test results

The suite runs under the Unity Test Framework inside the private project. Last full run: 37 EditMode tests, 0 failures, 0 compile errors on Unity 6000.3.3f1. The test sources above are readable on their own — the three data structures are plain C# with no engine dependencies, which is exactly what makes them testable in isolation.
